# B站动态页重构（油猴脚本）

主要改动在 https://t.bilibili.com/ 动态首页和视频播放页；顶栏精简在 B 站各页面都生效。只在你自己的浏览器里生效。效果图见 `preview-light.jpg`、`preview-dark.jpg`（动态页，v1.0 时截的，那时还没隐藏右侧横幅）、`preview-drawer.jpg`（播放页菜单）和 `preview-drawer-up.jpg`（菜单里点开一位 UP；用测试数据截的，列表里的视频是拼的）。

## 做了什么

**动态页**
- **左侧关注列表**放在原来「正在直播」的位置，页面往下滚时它固定在顶部，类似 YouTube 的订阅列表。
  - 从上到下依次是：「全部动态」、优先关注、有新视频（右边有个小蓝点，鼠标停在上面能看到有几个）、其他关注（默认显示 10 位，可以展开）。
  - 可以搜索 UP，也能按 B 站的关注分组筛选。
  - 点一位 UP，中间显示 TA 的最近投稿，下方动态流也只显示 TA。再点一次，或点「全部动态」，就回到全部。中键或 Ctrl+点击会在新标签打开 TA 的空间。
  - 鼠标移到 UP 上，点右边的 ☆，就设为**优先关注**，同时加入 B 站「特别关注」（手机和别的电脑都同步）；再点一次就两边一起取消。
- **中间新视频墙**分「新视频」和「最近 N 天」两个标签。
  - 优先关注的 UP 排在最前。同一位 UP 的多个新视频合并成一张卡，显示「+N」。
  - 卡片上有两个按钮：「稍后再看」和「✓ 标为已看」。也可以一次「全部标为已看」，都能撤销。
  - 看过的视频显示进度条。浏览器标签页标题前显示新视频个数。
- 直播收进右侧一张折叠卡片，动态流里「直播了」的卡片也一并隐藏。
- 默认隐藏这几样：「发动态」输入框、右侧「社区中心」横幅、右下角「回到旧版」按钮。

**播放页**（`www.bilibili.com/video/…`、`/list/…`）
- 顶栏最左边多了一个 **≡**，和 YouTube 播放页一样，点开从左边滑出菜单；有新视频时 ≡ 右上角会出现蓝点。
- 菜单上半部分是首页、动态（有新视频时带小蓝点）、历史记录、稍后再看、我的收藏，下半部分就是动态页那份关注列表，☆ 也能用。
- 点列表里的 UP，菜单就地换成 TA 的最近投稿（菜单会变宽一点），页面不跳转，视频接着放。新视频带小蓝点，看过的显示进度条，正在播放的那个高亮。点左上角的 ‹ 回到关注列表，列表原来滚到哪还在哪。
  - 在 TA 的投稿里点视频，就在当前页打开，和 B 站右侧的推荐视频一样；想新开标签就中键或 Ctrl+点击。
  - 点 TA 的头像、名字，或者底部的「在 TA 的空间看全部投稿」，会在新标签打开 TA 的空间。
  - 想像以前那样到动态页里看 TA，就中键或 Ctrl+点击列表里的 UP。
- 正在看的视频自动算看过，不会再显示成新视频。
- 收起菜单：按 Esc、点菜单外面，或者点菜单左上角的 ≡ 都可以。

**全站顶栏**（`www`、`t`、`search`、`space` 这几个子站）
- 去掉游戏中心、会员购、赛事、活动入口（比如现在的「S16」）、下载客户端、创作中心、投稿，只留首页、番剧、直播、漫画和右边的个人入口。
- 只用样式藏起来，不改顶栏本身。设置里「精简顶栏」可以关掉。

动态页和播放页共用同一份数据，在哪边刷新过，另一边打开时直接就有。动态页新视频墙右上角的 ⚙、播放页菜单右下角的 ⚙，都能打开设置，上面每一项都能开关。

**「新视频」怎么算**：最近 N 天发布（默认 3 天）、不在 B 站观看历史里（手机上看过的也算看过），并且没在这里点开过、也没标为已看。第一次安装时，只把最近 24 小时的视频算作新视频。

**关注列表多久更新一次**：每次刷新都会比对你当前的关注人数，有变化（关注或取关了谁）就立刻重新拉取，取关的人连同 TA 的视频一起清掉；就算人数没变，最多 2 小时也会重拉一次。点「刷新」按钮会强制重拉。

## 安装

1. 浏览器装上 Tampermonkey（篡改猴）扩展。Chrome/Edge 新版本还要在扩展详情页打开「允许运行用户脚本」（旧版本是打开扩展页右上角的「开发者模式」）。
2. **一键安装 / 更新**：直接打开 [`bili-dynamic-revamp.user.js` (Raw)](https://raw.githubusercontent.com/chasezhang1999/bili-dynamic-userscript/main/bili-dynamic-revamp.user.js)，Tampermonkey 会自动弹出安装或升级页面；日常在 Tampermonkey 面板点「检查更新」即可拉取新版。（手动安装：打开 Tampermonkey 管理面板 →「实用工具」→「从文件导入」，选 `bili-dynamic-revamp.user.js`；或者「添加新脚本」，把文件内容整个粘贴进去保存。）
3. 刷新 t.bilibili.com，或者随便打开一个视频。

## 须知

- **会写入 B 站账号的只有两样**：「稍后再看」按钮，以及 ☆ 同步特别关注（设置里可以关掉，关掉后 ☆ 只存在这个浏览器里）。特别关注是 B 站自己的功能，B 站会对特别关注的 UP 推送更新提醒。
- 下方动态流只能筛选 B 站「最近更新」名单里的 UP。不在名单里的 UP，中间照样能看 TA 的投稿，但下方仍显示全部动态，页面上会有提示。
- 「直播了」卡片是按文字认的。测试时页面上恰好没有这种卡片，这一项还没实测到。
- 为了精简顶栏，脚本在 B 站各页面都会运行；除了动态页和播放页，其他页面上它只加一段样式，不做别的事。
- 播放页菜单里一位 UP 的投稿，取的是 TA 最近一页动态里的视频（20 条以内），更早的点「在 TA 的空间看全部投稿」。
- 如果 B 站改版导致脚本失效，页面会保持原样，不会坏掉。按 F12 打开控制台，搜索「[动态页重构]」能看到原因。

## 更新记录

- **1.3.0**：播放页菜单里点 UP 不再跳去动态页，而是在菜单里直接列出 TA 的最近投稿，点视频在当前页打开。正在播放的视频自动算看过。关注列表刷新、点 ☆ 之后不再跳回顶部。同时开着几个 B 站页面时，已看记录不会再互相覆盖。
- **1.2.0**：全站顶栏精简，去掉游戏中心、会员购、赛事、活动入口、下载客户端、创作中心、投稿。
- **1.1.2**：关注列表和播放页菜单里的新视频数字改成小蓝点（个数在鼠标悬停提示里）；只有图文、转发等别的动态时显示空心灰圈。菜单左上角的 B 站 logo 偶尔显示成文字的问题也修了。
- **1.1.1**：修复「打开视频后整条顶栏消失」。原因是 ≡ 被插进了 B 站服务器渲染好、但前端还没接管的顶栏里，接管时出错；现在 ≡ 盖在顶栏左边，不再动顶栏本身。
- **1.1.0**：播放页加 ≡ 菜单；☆ 同步 B 站特别关注；隐藏「社区中心」和「回到旧版」；取关后关注列表立刻更新。
- **1.0.0**：动态页关注列表、新视频墙、直播收进右侧。
